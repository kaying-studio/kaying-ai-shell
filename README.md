# kaying-ai-shell
xshell like, SSH client Connection manager for macOS and other platform windows and etc.     
主要定位与：**好用的ssh连接管理**    

## v1.0.1 release cn      
1，重新调整了UI   
2，右侧增加 sftp   
3，右侧增加 infoPanel 展示当前连接的服务器的基础信息、历史指令、指令自动输入、指令复制等   
4，右侧增加 ai Panel, 可以选中服务器上的内容或日志，直接问 AI   
5，增加应用的配置数据备份导出和导入   
6，其它已知Bug   

## v1.0.1 release en   
1. Re-adjusted the UI.
2. Added sftp on the right side.
3. Added infoPanel on the right side to display basic information, historical commands, automatic command input, command copying, etc. of the currently connected server.
4. Added ai Panel on the right side, allowing users to select content or logs on the server and directly ask AI.
5. Added backup, export, and import of application configuration data.
6. Other known bugs
   
**current is free without regist**
